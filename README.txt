B3 is a multi-page experience with seamless in-site navigation. The next page is prefetched when possible, shared styles stay in place during navigation, and a subtle progress bar appears only if a page takes longer to load. The music player starts on a user-initiated page change and its audio element stays mounted while pages change, so playback continues. Browsers require a user interaction before allowing audio playback; use the music button if playback is blocked. Serve the folder through a local or hosted HTTP server; opening the HTML files directly with file:// prevents in-page navigation. For Vercel or another static host, set this folder (the one containing index.html and config.js) as the project root, then redeploy after changes. Pages: index.html → wishes.html → journey.html → memories.html → surprise.html → favorite.html → goodbye.html. Edit config.js to personalize the site and choose a soundtrack. The bundled soundtrack is music/music.mp3; replace it or update the music path in config.js. Replace photo placeholders in /photos.
